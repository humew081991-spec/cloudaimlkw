Course curriculum

8 modules · 2 days (modular)

Module 01

Linux Fundamentals

  • Linux distributions — RHEL, CentOS Stream, Ubuntu Server, and their differences
  • File system hierarchy — where things live and why
  • Essential commands — navigation, file operations, piping, and redirection
  • Text editors — vi/vim basics and nano
  • Getting help — man pages, info, and --help

Module 02

Users, Groups & Permissions

  • User and group management — useradd, usermod, groupadd
  • File permissions — read, write, execute, and the permission model
  • Special permissions — SUID, SGID, and sticky bit
  • sudo configuration and privilege escalation
  • Password policies and account management

Module 03

Process & Service Management

  • Process management — ps, top, kill, nice, and job control
  • Systemd — units, services, targets, and journald
  • Managing services — start, stop, enable, disable
  • Scheduling — cron and at for task automation
  • Resource monitoring — CPU, memory, and disk usage

Module 04

Storage & File Systems

  • Disk partitioning — fdisk, parted, and partition types
  • Logical Volume Manager (LVM) — PVs, VGs, and LVs
  • File system creation and mounting — ext4, xfs
  • /etc/fstab — persistent mounts
  • NFS and SMB — network storage configuration

Module 05

Networking

  • Network configuration — nmcli, nmtui, and configuration files
  • Static IP, DNS, and gateway configuration
  • firewalld — zones, services, and port rules
  • SELinux — concepts, modes, and managing contexts
  • SSH — key-based authentication, sshd configuration, and tunnelling
  • Network troubleshooting — ss, netstat, tcpdump, ping, traceroute

Module 06

Package Management & Software

  • RPM and dnf/yum — installing, updating, and removing packages on RHEL
  • apt and dpkg — package management on Ubuntu
  • Repository configuration
  • Subscription Manager — registering RHEL with Red Hat
  • Software compilation from source — when and how

Module 07

Shell Scripting & Automation

  • Bash scripting fundamentals — variables, quoting, and expansions
  • Control flow — if/else, for loops, while loops
  • Functions and script organisation
  • Input/output handling — stdin, stdout, stderr
  • Practical automation scripts for IT administration
  • Introduction to Ansible for infrastructure automation

Module 08

Linux for VMware & OpenShift

  • open-vm-tools — installation and configuration for VMware VMs
  • RHEL on Nutanix AHV — Nutanix Guest Tools and best practices
  • Storage configuration for database and application servers
  • System tuning for OpenShift nodes — kernel parameters and resource limits
  • RHCSA exam preparation — exam format, domains, and practice tasks

Frequently asked questions

I only know Windows — is this training suitable for me?

Yes — the first module assumes no prior Linux knowledge. The training is deliberately designed for Windows-focused infrastructure engineers who need to build practical Linux skills for modern environments that include RHEL, Ubuntu, and OpenShift.

Does this training prepare me for the RHCSA exam?

The curriculum covers all RHCSA (EX200) exam objectives. The final module specifically addresses exam format and practice tasks. Most candidates find this training significantly accelerates their RHCSA preparation compared to self-study.

Is RHEL or Ubuntu covered?

Both — the core modules use RHEL as the primary platform (more common in enterprise), with Ubuntu differences highlighted throughout. The package management module covers both dnf/yum and apt explicitly.

How does Linux knowledge help with OpenShift and containers?

OpenShift runs on RHEL CoreOS and requires solid Linux fundamentals to operate effectively — particularly for troubleshooting node issues, managing storage, configuring networking, and understanding system logs. Linux competence is the foundation for all container platform work.

Can this be delivered as a corporate on-site training for our IT team?

Yes — corporate on-site delivery is available across Kuwait and the Gulf region. We can customise the content to focus on the specific Linux distributions and use cases most relevant to your environment.
