Course curriculum

8 modules · 2–3 days (modular)

Module 01

Active Directory Fundamentals

  • AD DS architecture — forests, domains, trees, and trusts
  • Domain controllers — installation, promotion, and demotion
  • Users, groups, computers, and Organisational Units (OUs)
  • Active Directory Sites and subnets — replication topology
  • FSMO roles — understanding and transferring

Module 02

Group Policy Management

  • GPO structure — GPMC, GPO creation and linking
  • User and computer configuration — common policy settings
  • Security filtering and WMI filtering
  • Loopback processing and GPO precedence
  • Troubleshooting GPO application — gpresult, rsop

Module 03

DNS, DHCP & Infrastructure Services

  • Active Directory-integrated DNS — zones and records
  • DNS troubleshooting — nslookup, dig, and common failure patterns
  • DHCP scope configuration, reservations, and failover
  • Windows Failover Clustering for DHCP and file services
  • DFS Namespace and DFS Replication for distributed file services

Module 04

Active Directory Migration & Restructuring

  • Domain and forest functional level upgrades
  • In-place OS upgrade for domain controllers
  • ADMT — inter-forest and intra-forest user migration
  • UPN suffix management — preparing for Entra sync
  • Pre-migration audit — stale accounts, empty OUs, and legacy objects

Module 05

Microsoft Entra ID & Hybrid Identity

  • Entra ID architecture — tenants, directories, and licensing tiers
  • Entra Connect — installation and synchronisation configuration
  • Password Hash Synchronisation vs Pass-Through Authentication vs Federation
  • Synchronisation scope — OU filtering and attribute mapping
  • Entra Connect Health — monitoring synchronisation

Module 06

Conditional Access & MFA

  • Legacy authentication protocols — discovery and remediation
  • Conditional access policy design — named locations, device compliance, risk
  • Report-Only mode — staged rollout strategy
  • MFA registration policy and user onboarding
  • Entra ID Protection — risk-based access policies
  • Privileged Identity Management (PIM) — just-in-time access

Module 07

Exchange to M365 & SharePoint Online

  • Exchange hybrid configuration and mailbox migration
  • Exchange 2010/2013/2016 to Exchange Online migration
  • Cutover, staged, and hybrid migration types
  • SharePoint Online deployment and migration
  • Microsoft Teams integration with Entra ID

Module 08

Intune Device Management

  • Microsoft Intune architecture and MDM/MAM concepts
  • Device enrolment — Windows Autopilot, bulk enrolment
  • Compliance policies and device configuration profiles
  • Conditional access with device compliance
  • App deployment and protection policies

Frequently asked questions

Does the trainer have experience with Entra migrations in Kuwait?

Yes — the trainer has executed Entra ID migrations in Kuwait enterprise environments, including legacy authentication dependency audits, Entra Connect deployment, and phased conditional access rollout. The training is built from those real project experiences.

Our AD environment is complex and old — is this training still relevant?

Yes — and this is exactly where hands-on field experience matters. The migration and restructuring module specifically addresses pre-migration cleanup, legacy object remediation, and the gotchas that surface in complex, long-running AD environments.

Can this training cover our specific version of Windows Server?

Yes — the content can be tailored to Windows Server 2012 R2, 2016, 2019, or 2022 depending on your environment. Corporate on-site training is typically delivered against your specific infrastructure.

Does this training cover Microsoft 365 licensing?

The licensing module within Entra ID fundamentals covers the key licensing differences between Entra ID Free, P1, and P2 — including which features (Conditional Access, PIM, Identity Protection) require which licence tier. This is critical for planning Entra migrations correctly.

Is this training aligned to Microsoft certification exams?

Yes — the content aligns to AZ-800/AZ-801 (Windows Server Hybrid Administrator), SC-300 (Identity and Access Administrator), and MD-102 (Endpoint Administrator) exam objectives. Post-training certification guidance is included.
