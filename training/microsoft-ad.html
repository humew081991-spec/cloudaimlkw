Microsoft Active Directory & Entra ID Training
Kuwait & Online

Microsoft identity infrastructure training covering both on-premises Active Directory and Microsoft Entra ID (formerly Azure AD). From day-to-day AD administration through to hybrid identity design and full Entra migration — delivered by an engineer who has executed these migrations in Kuwait enterprise environments.

Topics covered

Active Directory Administration

Users, groups, OUs, Group Policy, DNS, DHCP, FSMO roles, and replication. Day-to-day AD management and troubleshooting for Windows Server environments.

Group Policy Management

GPO design, linking, filtering, and troubleshooting. Applying security settings, software deployment, and drive mapping across your organisation.

Active Directory Migration

Migrating AD from older Windows Server versions — domain restructuring, trust relationships, ADMT, and cutover planning with minimal disruption.

Microsoft Entra ID Fundamentals

Understanding Microsoft Entra ID — how it differs from on-premises AD, licensing tiers, and what hybrid identity means in practice.

Entra Connect & Hybrid Identity

Deploying and configuring Entra Connect — synchronisation scope, password hash synchronisation, pass-through authentication, and UPN alignment.

Conditional Access & MFA

Designing and deploying conditional access policies — MFA rollout, named locations, device compliance, and the staged approach from Report-Only to enforcement.

Who this is for

Windows Server administrators managing Active Directory, IT teams planning Entra ID migration, engineers responsible for identity infrastructure in Kuwait enterprises.
