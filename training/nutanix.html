Course curriculum

7 modules · 2 days (modular)

Module 01

Nutanix Architecture Fundamentals

  • Nutanix HCI architecture — nodes, blocks, and cluster design
  • Controller VM (CVM) — role and configuration
  • AHV hypervisor architecture vs VMware ESXi
  • Nutanix distributed storage fabric — how data is written and protected
  • Replication Factor (RF2/RF3) and erasure coding explained

Module 02

Prism Element Administration

  • Prism Element UI overview — dashboards and navigation
  • Storage container creation and configuration
  • VM management — creation, cloning, snapshots
  • Networking in AHV — virtual switches, VLANs, and bond modes
  • Alerts, health checks, and NCC health diagnostics
  • Cluster configuration and node management

Module 03

Prism Central

  • Prism Central deployment and scale-out configuration
  • Multi-cluster management from a single pane
  • Categories, policies, and tagging
  • Calm — application lifecycle management basics
  • Flow Network Security — microsegmentation introduction
  • Prism Central analytics and capacity planning

Module 04

AHV Operations & VM Management

  • AHV virtual machine best practices
  • Nutanix Guest Tools (NGT) — installation and features
  • VM migration from VMware ESXi to AHV using Nutanix Move
  • VM migration from Hyper-V to AHV
  • Live migration (AHV vMotion equivalent)
  • VM templates and image service

Module 05

Data Protection & Replication

  • Protection Domains — snapshot schedules and retention
  • Remote site configuration for replication
  • Recovery Plans for DR failover and failback
  • Metro Availability — synchronous replication for near-zero RPO
  • Nutanix DR best practices for banking and government environments

Module 06

Cluster Upgrades & Lifecycle Management

  • Nutanix Lifecycle Manager (LCM) — automated upgrades
  • AOS upgrade procedure — pre-checks and sequencing
  • AHV upgrade procedure
  • Foundation — cluster imaging and re-imaging
  • Cluster expansion — adding nodes to existing clusters

Module 07

NCP Exam Preparation

  • NCP-MCI exam structure and domains
  • High-frequency exam topics — storage, networking, DR
  • Practice scenario walkthroughs
  • Exam technique and time management
  • NCM-MCI pathway — what comes after NCP

Prerequisites

  • Familiarity with networking concepts (VLANs, subnets, routing)

Yes — the trainer holds Nutanix Certified Master (NCM-MCI) certification and has deployed Nutanix across multiple Kuwaiti banks, government ministries, and enterprise environments, including multi-site clusters with production and DR.
