Topics covered

Windows Server Administration

Installation, configuration, roles and features, user management, storage management, and day-to-day operations of Windows Server 2019 and 2022.

Hyper-V Virtualisation

Microsoft Hyper-V architecture, VM management, virtual networking, live migration, and Hyper-V Replica for basic DR. Comparison with VMware and Nutanix AHV.

Windows Failover Clustering

Designing and implementing Windows Server Failover Clusters for high availability — shared storage, cluster validation, and managing clustered roles and services.

DNS & DHCP

Windows DNS server configuration, zone management, conditional forwarding, and DHCP scope design for enterprise environments.

File Services & DFS

Windows file server configuration, NTFS permissions, Distributed File System (DFS) for namespace and replication, and storage management.

Windows Server Upgrades & Migration

In-place upgrades and cross-version migrations for Windows Server — planning, pre-checks, and post-migration validation for production environments.
