Course curriculum

7 modules · 2 days (modular)

Module 01

Windows Server Fundamentals

  • Windows Server editions — Standard, Datacenter, and Server Core
  • Installation options — GUI, Server Core, and Nano Server
  • Server Manager and Windows Admin Center — administration interfaces
  • Roles, Role Services, and Features — installation and configuration
  • Windows Server licensing — CALs, OEM vs Volume

Module 02

Core Infrastructure Services

  • DNS Server — zones, records, forwarders, and DNS troubleshooting
  • DHCP Server — scope configuration, reservations, and DHCP failover
  • File and Storage Services — shares, NTFS permissions, and quotas
  • Print and Document Services
  • Remote Desktop Services — basic configuration
  • Web Server (IIS) — basic site management

Module 03

Windows Server Storage

  • Disk Management — MBR vs GPT, basic vs dynamic disks
  • Storage Spaces — virtual disks, pools, and resiliency settings
  • iSCSI Initiator — connecting to SAN storage
  • Data Deduplication — enabling and monitoring
  • Backup with Windows Server Backup and Veeam integration overview

Module 04

Hyper-V Virtualisation

  • Hyper-V architecture — Type 1 hypervisor on Windows Server
  • VM creation, configuration, and management
  • Virtual networking — internal, private, and external switches
  • Hyper-V storage — VHD, VHDX, and pass-through disks
  • Live Migration and Quick Migration
  • Hyper-V Replica — basic DR configuration
  • Hyper-V vs VMware — feature comparison and migration considerations

Module 05

Windows Server Failover Clustering

  • Failover Cluster architecture and quorum models
  • Cluster validation wizard — prerequisites and checks
  • Cluster shared volumes (CSV) — configuration and management
  • Clustered roles — File Server, Hyper-V, and generic services
  • Cluster-Aware Updating (CAU) — patching clustered nodes
  • Troubleshooting failover cluster issues

Module 06

Security & Group Policy

  • Windows Firewall with Advanced Security — inbound/outbound rules
  • Group Policy for Windows Server — computer configuration
  • Local security policy — password policy, audit policy, user rights
  • Windows Defender and endpoint protection basics
  • Event Viewer and Windows event log management

Module 07

Monitoring, Updates & Upgrades

  • Performance Monitor and Resource Monitor — identifying bottlenecks
  • WSUS — patch management for Windows Server and client environments
  • Windows Server in-place upgrade — 2012 → 2016 → 2019 → 2022
  • Server migration — Windows Server Migration Tools
  • Best practices for production change management in Kuwait enterprises

Prerequisites

Frequently asked questions

Does this training cover Windows Server 2022?

Yes — the training covers Windows Server 2019 and 2022 as the primary platforms, with references to 2016 where relevant for upgrade planning. Content is kept current with the latest features including Storage Migration Service and Windows Admin Center.

Is Hyper-V covered in enough depth to replace a dedicated Hyper-V course?

The Hyper-V module provides solid operational coverage — VM management, virtual networking, storage, and basic DR with Hyper-V Replica. For advanced Hyper-V topics (SCVMM, advanced SDN), a dedicated session can be added to corporate programmes.

How does this training address Windows Server in a Nutanix or VMware environment?

The course addresses Windows Server as a guest OS in virtualised environments — VMware Tools/open-vm-tools on Windows, storage best practices for VMs, and how Hyper-V compares to vSphere and Nutanix AHV operationally.

Can this training be combined with the Active Directory course?

Yes — Windows Server and Active Directory training are commonly delivered together as a combined 3-4 day programme. This is a popular option for corporate on-site training where teams need both server administration and identity management skills.

Is this training relevant for engineers preparing for Microsoft certifications?

Yes — the content aligns to the AZ-800 (Administering Windows Server Hybrid Core Infrastructure) and AZ-801 (Configuring Windows Server Hybrid Advanced Services) exam objectives. Certification guidance is included in the final session.
