Course curriculum

7 modules · 2–3 days (modular)

Module 01

Container & Kubernetes Fundamentals

  • Containers vs virtual machines — architecture differences explained for infra engineers
  • Docker and Podman — images, containers, and registries
  • Kubernetes architecture — control plane, worker nodes, etcd
  • Pods, ReplicaSets, Deployments, and Services — core resource types
  • ConfigMaps, Secrets, and Namespaces

Module 02

OpenShift Architecture & Installation

  • OpenShift vs upstream Kubernetes — what OpenShift adds
  • IPI vs UPI installation — when to use each
  • OpenShift on Nutanix AHV — IPI deployment walkthrough
  • OpenShift on VMware vSphere — IPI and vSphere CSI integration
  • Bootstrap process and cluster operator overview

Module 03

OpenShift Administration

  • Web console navigation — projects, workloads, networking, storage
  • oc CLI — authentication, resource management, debugging
  • OpenShift projects and RBAC — users, groups, and role bindings
  • Image streams, build configs, and DeploymentConfigs
  • OpenShift operators — the Operator Hub and operator lifecycle

Module 04

Storage in OpenShift

  • Persistent Volumes (PV) and Persistent Volume Claims (PVC)
  • Storage Classes — dynamic provisioning
  • Nutanix CSI driver — volumes and files storage classes
  • vSphere CSI driver configuration
  • CSI snapshots for application-consistent data protection
  • Storage class best practices for production environments

Module 05

Networking & Ingress

  • OpenShift SDN — OVN-Kubernetes architecture
  • Services — ClusterIP, NodePort, LoadBalancer
  • Routes and Ingress — exposing applications externally
  • Network Policy — pod-to-pod traffic control
  • MetalLB and external load balancer integration
  • Troubleshooting OpenShift networking

Module 06

Day-2 Operations & Upgrades

  • Cluster monitoring — Prometheus, Alertmanager, Grafana
  • Logging — OpenShift logging stack (EFK)
  • Cluster upgrades — update channels, update graph, and upgrade execution
  • Machine Config Operator — node configuration management
  • Etcd backup and restore
  • Troubleshooting common OpenShift issues

Module 07

VMware Admin to OpenShift Engineer

  • Mapping VMware concepts to OpenShift — a side-by-side comparison
  • Networking: port groups → network policies
  • Storage: datastores → storage classes and PVCs
  • HA: vSphere HA → pod disruption budgets and ReplicaSets
  • Career path from infrastructure engineer to platform engineer
  • CI/CD basics for infrastructure professionals

Frequently asked questions

Do I need Kubernetes experience before attending?

No — the first module starts from container fundamentals and builds up systematically. The training is specifically designed for infrastructure engineers coming from VMware or traditional IT backgrounds, not developers.

Does this training cover OpenShift on Nutanix specifically?

Yes — Module 2 includes a dedicated walkthrough of OpenShift IPI deployment on Nutanix AHV, including Nutanix CSI driver configuration and Prism Central integration. This is based on real production deployments in Kuwait.

How does this differ from Red Hat's official training?

Red Hat's official training is comprehensive but general. This training is specifically tailored for infrastructure engineers in Gulf region enterprise environments — using examples from actual Kuwaiti banking and government deployments, and addressing the operational context your team will actually face.

Is this training useful for engineers who are not moving into DevOps?

Yes — many infrastructure engineers need to operate OpenShift clusters deployed by development teams, or manage the underlying infrastructure for OpenShift without writing application code. This training covers exactly that operational role.

Can this training help prepare for Red Hat OpenShift certification?

The content aligns closely with the EX280 (Red Hat Certified Specialist in OpenShift Administration) exam objectives. It is not an official Red Hat exam preparation course, but candidates typically find it significantly reduces their remaining study time.
