Course curriculum

7 modules · 2–3 days (modular)

Module 01

vSphere 8 Fundamentals

  • ESXi architecture and installation
  • vCenter Server deployment and configuration
  • Virtual machine creation, cloning, and snapshot management
  • vSphere networking — standard and distributed switches
  • Storage concepts — datastores, VMFS, NFS

Module 02

vSphere Cluster Operations

  • vSphere HA — configuration, admission control, and failure scenarios
  • DRS and resource pools — workload balancing policies
  • vMotion and Storage vMotion — live migration configuration
  • vSphere lifecycle management — patching and upgrades with LCM
  • Performance monitoring with vCenter performance charts and alarms

Module 03

VMware vSAN

  • vSAN architecture — all-flash and hybrid configurations
  • vSAN cluster creation and disk group design
  • Storage policies — FTT, RAID configurations, and object placement
  • vSAN deduplication, compression, and encryption
  • vSAN health monitoring and troubleshooting
  • vSAN upgrade procedures

Module 04

NSX-T Network Virtualisation

  • NSX-T architecture — management, control, and data planes
  • Transport nodes, host preparation, and N-VDS configuration
  • Logical switching — overlay and VLAN transport zones
  • Tier-0 and Tier-1 gateways — routing and NAT
  • Distributed Firewall — micro-segmentation and security policies
  • NSX-T troubleshooting and monitoring

Module 05

VMware Horizon VDI

  • Horizon 8 architecture — Connection Server, Unified Access Gateway
  • Desktop pool types — instant clone, full clone, and manual
  • App Volumes — application lifecycle management
  • Dynamic Environment Manager (DEM) — user environment personalisation
  • Horizon performance optimisation and troubleshooting

Module 06

AVI Networks Load Balancing

  • AVI Networks (NSX ALB) architecture and components
  • Virtual services, pools, and health monitors
  • SSL termination and certificate management
  • Integration with VMware NSX-T
  • Monitoring and analytics

Module 07

VMware Upgrades & Migration Planning

  • vSphere 6.x to 7/8 upgrade planning and pre-checks
  • In-place vs fresh installation upgrade strategies
  • vCenter upgrade procedures — VCSA migration
  • VMware to Nutanix migration assessment using Nutanix Move
  • Broadcom licensing impact analysis and migration options

Prerequisites

Frequently asked questions

Do I need a VMware environment to attend?

No — for online sessions we use shared lab environments. For corporate on-site training we can use your existing vSphere environment as the hands-on reference, which makes the training immediately applicable.

Is this training aligned to VMware VCP certification?

Yes — the vSphere and NSX-T modules are aligned to the VCP-DCV and VCP-NV exam objectives respectively. On completion you will have covered the core knowledge areas for both certifications.

Can the training be customised for our specific VMware version?

Yes — we can tailor content to vSphere 6.7, 7.x, or 8.x depending on your environment. Corporate on-site sessions are typically run against your specific version.

How does this training address the Broadcom licensing changes?

The final module specifically covers the impact of Broadcom's licensing changes on existing VMware deployments and provides a structured framework for evaluating migration options — including Nutanix, OpenShift, and renegotiated VMware.

What is the group size for in-person sessions?

In-person Kuwait sessions are capped at 8 participants to maintain interaction quality. Corporate on-site sessions can accommodate larger groups with adjusted format.
